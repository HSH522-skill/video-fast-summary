# video-fast-summary

Extracts titles, summaries, and key points from Bilibili/Douyin/Xiaohongshu/YouTube links or local videos. Dual-engine (Tongyi Tingwu + Whisper) ensures reliability. One-command setup installs all dependencies and runs the demo.
